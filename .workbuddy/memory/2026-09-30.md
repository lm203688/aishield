### 关键错误与修复
1. **`datetime.now()` 内部 `)` 使 lookahead 提前 break**：
   `recall\s*\((?![^)]{0,500}(scope|...))[^)]{0,500}\)` 遇到嵌套 `datetime.now()`
   会先命中 `)` → 改为"文件级 guards"判断

2. **red-team pack `fail_on="impossible"` 语义错误**：
   初版 `_severity_rank("impossible")=-1` 导致任何 finding 都 fail
   → `if fail_on in ("off","impossible"): passed=True` 特判

3. **`_PACKS_DIR` 路径写错**：
   初版 `os.path.dirname(os.path.abspath(__file__))` = `scanner/`，JSON 写到错位置
   → `os.path.join(dirname(__file__), "policy_packs")`

4. **Python 字符串拼接 `'` 结尾错误**（2 处）：
   `"context: 'save...'"` 隐式拼接下一段以 `'` 开头会语法错误
   → 改为 `'context: "save..."'` 用单引号包裹

5. **red_team_probe expected_types 命名错误**：
   初版用自定义类型名（`memory_context_poisoning` 等）→ 全部 FAIL
   → 改为 OWASP 类别（`MCP06`）

6. **`test_dist_build_in_sync_with_src` 失败**（76 vs 68）：
   src/dist 工具数不一致 → `node_modules/.bin/tsc` 重建 dist

7. **`test_all_tools_documented` 失败**：
   新 7 工具未在 README 里 → 加 "Ecosystem Support" 段
