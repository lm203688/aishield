## 文章一 · 掘金 / 知乎长文（约 900 字）

**标题：你的 MCP Server 真的安全吗？聊聊 agent 时代工具扫描的"本地优先"陷阱**

MCP（Model Context Protocol）让大模型直接调用外部工具，agent 生态一夜爆发。但随之而来的安全问题被很多人低估：当你把一个第三方 MCP server 接进自己的 agent，你其实是在授予它执行代码、读文件、发网络请求的能力。

更反直觉的是——**很多所谓"安全扫描器"，会真的去执行你 server 配置里的命令**。等于你请来查毒的医生，先把病毒在自己身上跑了一遍。

### 扫描器自己的攻击面

一个典型的 MCP server 描述（tool description / manifest）里可能藏着：
- 诱导性指令（prompt injection），让 agent 在调用时绕过你的约束；
- 伪装成正常工具的"陷阱工具"，等待被调用时执行恶意逻辑；
- 依赖投毒：一个被篡改的 npm 包，在 install 阶段就动手脚。

如果扫描器为了"验证"把工具真实跑起来，那它和攻击者之间只差一个配置。这也是为什么业界开始强调**本地优先（local-first）**的扫描范式：代码不出机、不执行被扫对象里的任何命令。

### 一个本地优先的开源实现

AIShield 是这类思路的一个开源实现（MIT，零第三方运行时依赖，仅用标准库 urllib）：
- **绝不 spawn 被扫配置里的命令**——这是它的核心不变量，竞品里少有坚持这一条的；
- 规则底座 **227 条 MCP + 233 条 Skill** 规则，对齐 OWASP MCP Top 10 与 OWASP Agentic AI Top 10（ASI01–ASI10）；
- 输出 5 维安全评分 + 徽章等级，并给出具体发现；
- 可选接入远程 LLM 做语义分析，但**默认全离线**，你的代码永远不离开本机。

基准表现：20 个良性样本零误报，10 个恶意样本 10/10 拦下。

### 怎么用

```bash
npx -y aishield-mcp-server
```

接进你的 agent 工作流，或单独对某个 GitHub 上的 MCP / skill 仓库跑一遍静态体检。它不触达网络、不执行未知代码，适合 CI 或本地预扫阶段。

### 写在最后

agent 安全不是一个"扫得多"的军备竞赛，而是一个"不给自己制造新攻击面"的纪律问题。如果你也在做 MCP / agent 工具，建议把"本地优先、静态优先、不执行被扫对象"作为选型的硬门槛。

项目地址：github.com/lm203688/aishield · npm 包 `aishield-mcp-server`

## 文章二 · 知乎回答 / 教程风（约 800 字）

**标题：手把手用开源扫描器给 MCP / agent 工具做安全体检（OWASP MCP Top 10 实战）**

很多人知道 OWASP 有 Top 10，但 MCP 自己的安全风险清单（OWASP MCP Top 10）和 Agentic AI Top 10（ASI01–ASI10）还比较新。这篇用一个开源、本地优先的扫描器 AIShield，带你实际跑一遍体检。

### 1. 安装（零依赖、可离线）

```bash
npx -y aishield-mcp-server
```

它只用 Python 标准库，不拉任何第三方包，所以它本身不会成为供应链风险。

### 2. 对一个公开 MCP server 跑扫描

把目标仓库地址丢给它，它会做静态分析（不执行仓库里的任何命令）。扫描产出 5 个维度的评分：提示注入抵抗、权限/作用域最小化、供应链完整性、数据外泄风险、整体健壮性，并给出徽章等级（gold / silver / bronze / none）与逐条发现。

### 3. 怎么读结果

- **良性零误报**：对自己写的、可信的工具应当几乎不报；若一片红，先怀疑规则是否过激。
- **恶意必拦**：对含诱导指令、伪装工具、依赖投毒的样本应当拦下并指明位置。
- **别只看总分**：维度分比总分更能告诉你"哪里弱"。如"供应链完整性"低，优先审 dependencies。

### 4. 为什么强调"本地优先"

传统 SaaS 扫描要把代码传上云。对 agent 工具这种"能执行代码"的东西，把源码传出去本身就是风险。本地优先 = 代码不出机、扫描器不执行被扫命令，只在你自己的机器上跑。

### 5. 接入工作流

- CI 阶段：对每次新增/更新的 MCP server 跑一遍，低于阈值不让合并；
- 本地预扫：接新工具前先体检；
- 运行时：部分能力可作 guardrail，在调用前做准入校验。

项目：github.com/lm203688/aishield · npm `aishield-mcp-server` · 规则 227 MCP + 233 Skill · MIT
