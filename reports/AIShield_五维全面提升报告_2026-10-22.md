## 0. 执行摘要

### 五维评分

| 维度 | 评分 | 一句话判定 |
|---|:---:|---|
| **全面性** | **6.5 / 10** | 覆盖面广（MCP+Agentic+供应链+身份+支付+多智能体），但**两个最大攻击族零覆盖** |
| **实用性** | **6.0 / 10** | 工程底座极硬（离线/零依赖/零误报/形式化），但**外部召回仅 40.6%**，真实可用性受限于检测效力 |
| **使用性** | **5.5 / 10** | `setup.py` 已修（有 install_requires）、ARTIFACT/Docker 齐备，但英文文档仅 3 篇、`llms.txt` 仅 640 字节 |
| **互动性** | **5.0 / 10** | 仍是"扫描→报告"单向管道；`.well-known/agent.json` 缺失、缺交互式修复与运行时反馈闭环 |
| **前沿性** | **7.0 / 10** | **最强项**：形式化穷举+完备性（R4 已达成）、神经符号零误报桥接、arXiv→规则自进化雷达；但**未对齐最新 AST 2026 / UASF v1.0** |
| **加权综合** | **6.0 / 10** | 骨架与工程纪律已达上游，**瓶颈从"有没有"转为"准不准、用不用、连不连"** |

### 三个决定性发现

1. **59.4% 的正样本落在两个零检出族**（`data_exfiltration` 176 + `indirect_prompt_injection` 176 = 352/593）。**间接提示注入正是 2026 年头号 Agent 攻击**（OWASP Agentic、InjecAgent 基准核心）。这是当前最严重的实用性与全面性缺口，也是**最高杠杆的改进点**——补上它，召回可从 40.6% 跃升。
2. **AST 2026 / UASF v1.0 零对齐**：全库 `AST01–AST10` 规则编号命中 **0 次**。而 OWASP 已于 2026-08 发布 **Agentic Skills Top 10 终版**与 **Universal Agentic Skill Format v1.0**，且把"恶意技能"列为 #1、"供应链"列为 #2 风险——**这恰是 AIShield 的主场（它扫 Skill），却未对齐新标准**。
3. **基线对比仍是纸面**：新增的 "Naive keyword heuristic / Random guess" 已跑（弱基线），但 **4 个真实竞品工具仍全部 `not_run`**。与"随机猜测"比赢不了审稿人。

## 1. 五维逐一评估

### 1.1 全面性 6.5 / 10

**已覆盖（实跑/核查确认）**
- 标准面：OWASP MCP Top 10（235 规则）、Agentic AI Top 10（ASI01–ASI10）、RSI L1–L5 威胁建模。
- 对象面：MCP server / Skill / GPTs / Prompt / 客户端配置 / 记忆 / RAG 语料 / 支付 / 身份 / A2A 多智能体 / 供应链 slopsquat。
- 外部语料：**593 正 / 517 负 / 18 族**，R1 门槛全绿（`unmet=无`）。
- 生命周期：静态扫描 + SBOM/SARIF + CI 门禁 + 运行时治理网关（POC）。

**关键缺口**
- ❌ **两族零检出**：`data_exfiltration`(29.7%)、`indirect_prompt_injection`(29.7%)，合计 59.4% 正样本无任何检出。
- ❌ **AST 2026 零对齐**：`AST01–AST10` 命中 0；UASF v1.0 未支持（仅 5 个文件偶发提及 SKILL.md）。
- ⚠️ 运行时仍弱：`runtime-immune-sidecar-poc`、eBPF 停留在 POC，未形成产品面。

### 1.2 实用性 6.0 / 10

**硬优势（真实且稀缺）**
- **零误报已被外部语料证实**：517 负样本 → **0 FP（0.0% [0.0%, 0.0%]）**。这是极强、极实用的性质（安全工具误报=没人用）。
- **绝不执行被扫代码**：FVI 门禁 PASS，穷举 64 态 + 完备性论证 + 4 变异体，机器可验。
- 离线/零依赖/可入 CI/SARIF/SBOM — 企业合规场景直接可用。

**致命短板**
- 🔴 **外部召回仅 40.6% [36.6%, 44.7%]**（593 中检 241）。内部 100% vs 外部 40.6%，实证了"内部语料过拟合"判断。
- 🔴 漏掉的恰恰是最高频真实攻击（间接提示注入）。**"零误报但漏掉头号攻击"在实用上等于不可靠**。
- ⚠️ 内部语料 57/57 的 100% 已不具代表性，**对外应改引用外部 40.6% / 0% FP**。

### 1.3 使用性 5.5 / 10

**改善项**：`setup.py` 已声明 `cryptography>=42`、`PyYAML>=6`（不再是零依赖声明缺失）；ARTIFACT.md、Dockerfile.artifact、一键复现命令已通（`--corpus external --bootstrap` 实跑成功）。

**待补**
- 英文文档仅 **3 篇**（国际化不足）。
- `llms.txt` 仅 **640 字节**（AI 可发现性形同虚设）。
- `.well-known/agent.json` **仍缺失**（Agent 原生入口缺位）。
- `api/server.py` 仍是 3000+ 行 god file（维护成本高，间接影响可用性）。

### 1.4 互动性 5.0 / 10

- 现有：MCP server、REST API、仪表盘（fleet / attack-graph）、技术雷达自进化（arXiv→规则）、守夜 spine。
- 缺口：**单向管道**（扫描→出报告），缺——
  - ❌ `.well-known/agent.json`（Agent 主动发现/调用入口）
  - ❌ 交互式修复建议 / 一键 remediate / 反馈闭环（用户确认误报→规则调优）
  - ❌ 运行时双向护栏（发现→阻断→验证→告警闭环，目前偏静态）
  - ⚠️ 与生态（市场/注册表/客户端）的双向联动弱

### 1.5 前沿性 7.0 / 10（最强维度）

**真实领先**
- ✅ **形式化 R4 已达成**：Python 层 `explore_with_report()` BFS 穷举 64 可达态、`coverage=1.0`、`complete=true` + 4 变异体判别力自证，**不依赖 Apalache 即满足完备性**。
- ✅ **神经符号零误报桥接**（`neuro_symbolic_probe.py`）：符号层当宪法、神经层只产候选、`ratify()` 绝不许神经层自升级——架构纪律领先。
- ✅ **自进化雷达**：arXiv 论文 → 自动转录候选规则 → 晋升 → 效果度量（signal→draft→promote→effect 闭环）。
- ✅ **RSI L1–L5 → ASI** 威胁建模（含真实被修的 L5 抑制缺陷）。

**落后点**
- ❌ AST 2026 / UASF v1.0 未对齐（新标准 2026-08 发布）。
- ⚠️ GGUF/llama.cpp 后端仍是 `NotImplementedError` 占位。
- ⚠️ eBPF 运行时、多智能体运行时编排仍是 POC。

## 2. 最新技术趋势与市场需求（外部调研）

| 趋势 | 要点 | 对 AIShield 的含义 |
|---|---|---|
| **① Skills 成为头号攻击面** | OWASP **Agentic Skills Top 10 (AST 2026)** 终版 + **Universal Agentic Skill Format v1.0**（2026-08）；#1 恶意技能、#2 供应链入侵 | **主场却零对齐** → 最高优先级补 AST 规则编号 + UASF 解析 |
| **② 标准体系快速分层** | OWASP Agentic Applications Top 10(2026)、MCP Top 10(2025)、AI Testing Guide(AITG)、State of Agentic AI Security & Governance v2.01(2026-06) | 需做"多标准映射矩阵"，成为合规抓手 |
| **③ 从静态扫描转向运行时治理** | 企业网关/运行时护栏（Palo Alto Prisma AIRS、Cyera AI Guardian、Cisco AI Defense）GA 化 | 静态是入场券，**运行时才是企业买单处** |
| **④ 多智能体编排** | A2A / multi-agent 协作、命名空间遮蔽、级联风险 | 已有 A2A 扫描，应升级为运行时级联防护 |
| **⑤ 可观测性与审计刚需** | 企业要 sovereignty + security + observability + compliance（Nutanix/Frost 2026）；零信任框架 | SBOM/SARIF/证据包是优势，需强化"审计就绪"叙事 |
| **⑥ 市场高速增长** | AI Agents 市场年复合 **+43.3%**（BCC Research 2026-01）；企业 AI 支出持续升但价值释放不均 | 需求侧旺盛，**合规 + 治理 + 可观测**是付费点 |

**需求侧结论**：买方要的不是"又一把扫描器"，而是 **"能进 CI、能过合规、有误报保证、能证明自己没乱来、还能在运行时拦住"** 的治理底座。AIShield 的零误报 + 形式化 + 离线恰好命中前四项，**唯独"运行时拦住"缺位**。

## 3. 全面提升方案（P0 → P3）

### P0｜修复 59.4% 零检出（最高杠杆，同时救实用性+全面性+SCI）

**目标**：把 `indirect_prompt_injection` 与 `data_exfiltration` 从 0% 拉起来，整体召回 40.6% → **≥70%**，同时**守住 0% FP**。

- **P0-1 根因定位**：这两个族 352 样本全部来自 InjecAgent（`dh_base/ds_base` 等），是**工具响应中的自然语言间接注入**，不是代码/配置模式。当前符号层（动作型正则）对自然语言注入无规则 → 神经层虽产候选，但 `ratify()` 要求符号确证 → **全部丢弃 → 零检出**。这是设计纪律的必然结果，不是 bug。
- **P0-2 补符号层 NL 注入规则**（保零误报铁律）：为"工具响应冒充指令"加动作型规则（如 `ignore (all )?previous|follow these instructions|as the (system|assistant)` + 工具响应上下文锚点），并**先在 517 负样本上验 0 FP** 再启用。
- **P0-3 补 data_exfiltration 规则**：外泄动作型模式（凭据+外发目的地共现、`169.254.169.254` 元数据端点、URL+secret 同句）。`DeterministicHeuristicBackend._EXFIL` 已有雏形，需升级为可 `ratify` 的符号规则。
- **P0-4 用 NSE 双轨 eval 验收**：`neuro_symbolic_probe.eval_corpus()` 断言 `bridge_adds_no_fp == True` 且 `recall_non_decreasing == True`。
- **验收**：`python scripts/benchmark.py --corpus external --bootstrap 1000` → 召回 ≥70%、零检出族 ≤0、FP 仍 0.0%。

> 若 P0-2/P0-3 能做成，**这本身就是论文最有力的新贡献**：证明"神经符号桥接可在保持 0% FP 的前提下，把覆盖从配置/供应链扩展到自然语言间接注入"。

### P1｜对齐 AST 2026 + UASF v1.0（前沿性 + 市场卡位）

- **P1-1** 在 `scanner/rules.py` 建立 **AST01–AST10 规则编号体系**（对齐 OWASP Agentic Skills Top 10），并把现有 Skill 扫描规则映射过去。
- **P1-2** 支持 **UASF v1.0** 解析（`scanner/workspace_scan.py` / `rules.py` 已触及 SKILL.md，升级为规范解析）。
- **P1-3** 出**多标准映射矩阵**文档（MCP Top10 × Agentic Top10 × AST 2026 × AITG × NIST AI RMF），作为合规卖点。
- **验收**：`grep -c "AST0" scanner/rules.py` ≥ 每类覆盖；映射矩阵进 `docs/`。

### P2｜SCI 收口：真实基线 + 人工 IAA

- **P2-1 让真实基线跑起来**（当前 4 个真实工具全 not_run）：优先做 **pip 可装的 agent-security-scanner-mcp**、**npm 的 Invariant mcp-scan**，补齐 `_invoke` 适配器（现全是 `raise RuntimeError`）。至少拿到 2 个真实基线数字。
- **P2-2 完成人工 IAA**：当前 κ=0.8673 来自**自动化 LCA**（manifest 诚实标注 "NOT human inter-annotator agreement"），`human_iAA_status: pending`。用已生成的 `human_iAA_template.csv` 完成 ≥2 人标注 → 出**真人 κ**，这是审稿硬门槛。
- **P2-3** 对外叙事统一：内部 100% 不再单独对外，主引用 **外部 40.6% 召回 / 0% FP**（修完 P0 后更新）。

### P3｜使用性 / 互动性补强

- **P3-1** 建 `.well-known/agent.json`（Agent 原生发现入口，当前缺失）。
- **P3-2** `llms.txt` 从 640 字节扩到**完整能力描述**（AI 可发现性）。
- **P3-3** 英文文档从 3 篇扩到覆盖 quickstart/architecture/benchmark/API/FAQ。
- **P3-4 加交互闭环**：误报反馈 → 规则调优；一键 remediate 建议；扫描→修复→复扫的闭环。
- **P3-5 运行时护栏产品化**（呼应趋势③）：把 sidecar/eBPF POC 推进为企业可部署的运行时阻断面。
