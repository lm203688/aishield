本地运行 · 代码不出机

三种方式，任选其一。无需注册、无需 API Key、无云端依赖。

方式一 · 作为 MCP Server

npx -y aishield-mcp-server

在 Claude Desktop / Cursor 配置中接入，即用即扫。

方式二 · 本地 API（localhost:8450）

python api/server.py

启动后访问 http://localhost:8450 ，无公网依赖、无需注册。

方式三 · CLI 扫描

python -m scanner.cli --target <repo>

对本地或远程仓库做一次性安全扫描。

更多渠道：Glama（lm203688/aishield）、npm aishield-mcp-server@4.2.2。详见 MCP 安全指南。
