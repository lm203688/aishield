常见问题

默认不会。扫描引擎在本地运行、零云端依赖。可选的「信任凭证签发 / 徽章」属于对外背书服务，仅在你主动生成凭证时调用，且凭证本身可由第三方凭 JWKS 公钥离线验真。

Pro / 终身是「使用额度」订阅（扫得多、API 优先）；认证服务是「按资产对外背书」的一次性费用（gold ¥39 / silver ¥19 / bronze ¥9），二者解决不同问题，可同时购买。
