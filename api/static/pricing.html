使用指南

常见问题

真的完全免费吗？

是的。AIShield 以 MIT License 开源，永久免费。没有付费墙、没有积分、没有订阅。你克隆仓库后在自己机器上运行即可，所有数据留在本地。

需要注册或 API Key 吗？

不需要。本地运行模式（python api/server.py 或 npx -y aishield-mcp-server）无需任何注册、密钥或云端账号。代码不出机。

和 aishield.ai 是同一款产品吗？

不是。本仓库是本地开源版 AIShield；aishield.ai 是同名商业云 SaaS（注册 / 密钥 / 计费式云端服务），二者是完全不同的产品。请认准 GitHub 仓库 lm203688/aishield。

数据会传到云端吗？

不会。扫描在本地执行，被扫配置不会被 spawn 执行，代码与数据均不出机。可选的远程 LLM 语义后端也由你自行配置。

如何安装？

作为 MCP Server：npx -y aishield-mcp-server；本地 API：python api/server.py；详见 MCP 安全指南 与 GitHub README。
