常见问题

Agent 适合积分制还是订阅制？

Agent 调用频率不可预测，不适合月度订阅。积分制按需消耗，Agent 自主决定何时调用、调用多少，符合 AI Agent 自主决策的特性。GitHub Actions（分钟数制）、Railway（资源额度）、Vercel（Credits）均采用类似模式。

1 分钱一次扫描，会不会太便宜？

现阶段 MCP 生态商业化极早期（不到 5% 的 MCP Server 有收入），核心目标是获客和生态建设。积分制降低试用门槛，让更多 Agent 和开发者接入，后续通过增值服务（委托链安全、文化完整性验证）提升客单价。

Agent 调用为什么半价？

Agent 是 AIShield 的核心服务对象，Agent 带来的调用量远超人类。半价策略鼓励 Agent 优先选择 AIShield，形成网络效应——Agent 用得越多，生态越繁荣，人类用户也越倾向选择已被大量 Agent 验证过的安全服务。

积分用完了怎么办？

1 元 = 100 积分，通过 /api/v1/account/recharge 充值。后续将接入支付宝和 Stripe，支持国际信用卡。充值无最低门槛，1 元起充。

和竞品比价格如何？

卖家精灵 MCP 月付 99 CNY 起仅 1000 次/月。AIShield 积分制 1 CNY = 100 次，无月费无到期，且 Agent 半价。对中小开发者和 Agent 生态来说，AIShield 成本仅为竞品的 1/10-1/50。
