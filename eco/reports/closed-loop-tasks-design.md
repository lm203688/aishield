# AIShield 闭环定时任务设计方案

> 核心原则：每个任务 = 一个完整闭环  
> 闭环公式：📥收集 → 🔍分析 → ✅决策 → ⚡执行/产出 → 🔄验证  
> 日期：2026-07-27

---

## 6个闭环总览

```
┌─────────────────────────────────────────────────────────────────┐
│  每日闭环（安全规则 + 成本优化）                                 │
│  📥 健康数据/检查记录/成本数据 → 🔍 异常检测 → ✅ 自动修复/告警 │
│  → ⚡ 修复规则/更新告警 → 🔄 验证昨日修复                        │
├─────────────────────────────────────────────────────────────────┤
│  每周一闭环（情报 → 规则 → 注册）                                │
│  📥 威胁情报/竞品/新Agent/Issues → 🔍 模式识别/差距分析          │
│  → ✅ 规则更新/Agent注册/需求入库 → ⚡ 更新代码/注册Agent         │
│  → 🔄 下周验证拦截率/注册质量                                    │
├─────────────────────────────────────────────────────────────────┤
│  每周五闭环（内容 → 发布 → 数据）                                │
│  📥 周报/生态数据/认证数据 → 🔍 选题分析/健康趋势                 │
│  → ✅ 确定选题/认证过期处理 → ⚡ 撰写文章/更新认证                │
│  → 🔄 下周追踪文章数据                                           │
├─────────────────────────────────────────────────────────────────┤
│  双周闭环（研发 → 进度 → 阻塞）                                  │
│  📥 ROADMAP/Issues/代码提交 → 🔍 进度偏差/阻塞分析               │
│  → ✅ 优先级调整 → ⚡ 更新ROADMAP → 🔄 下次验证                   │
├─────────────────────────────────────────────────────────────────┤
│  月度闭环（运营 → 决策 → 产品）                                  │
│  📥 月报/OKR/候选池 → 🔍 战略对齐/可行性评估                     │
│  → ✅ 产品决策/OKR调整 → ⚡ 更新ROADMAP/创建开发任务              │
│  → 🔄 下月验证执行                                               │
├─────────────────────────────────────────────────────────────────┤
│  季度闭环（战略 → 复盘 → 方向）                                  │
│  📥 季报/市场格局 → 🔍 Pivot判断 → ✅ 新方向/新OKR               │
│  → ⚡ 更新战略文档 → 🔄 下季度跟踪                               │
└─────────────────────────────────────────────────────────────────┘
```

## 任务1：每日闭环 — 安全规则 + 成本优化

**名称**：AIShield 每日闭环  
**频率**：每天 02:00 北京时间  
**Cron**：`0 2 * * *`

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📥 收集 — 5分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. WebFetch https://aishield.tools/api/v1/health 记录 version/rules_count/uptime
2. 读取 usage.json 分析 24h 请求量/错误率/热门端点/环比
3. 读取 api/data/security_inspections.json 昨日安全检查数据（总检查数/拦截数/风险类型分布）
4. 读取 api/data/call_records.json 昨日Token消耗与端点排名（如不存在跳过）
5. 读取 api/data/credit_transactions.json 当日充值/消费笔数与积分总额
6. 读取 api/data/accounts.json 统计总账户数/活跃账户数/总积分余额
7. WebSearch "github lm203688/aishield star" 记录 star 数
8. WebFetch https://github.com/lm203688/aishield/issues 检查新反馈

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 分析 — 3分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 安全分析：
   - 拦截率变化趋势（vs昨天、vs7天均值）
   - 是否出现新风险类型（security_inspections中新增的risk type）
   - 安全规则是否需要更新（连续3天同一风险类型拦截率上升 → 规则需强化）
2. 成本分析：
   - 单用户日消耗超阈值？（>500积分/日 → 标异常）
   - 昨日消耗偏离>200%？（vs前7天均值 → 突增异常）
   - 重复扣费？（同一record_id多次出现）
   - 积分消耗率>10%？→ 标警告
   - 账户余额为0且有API调用被拒（402错误）→ 统计耗尽用户数
3. 健康分析：
   - 错误率是否>5%？→ 标异常
   - 新GitHub Issues是否包含bug报告？→ 需修复

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 决策 — 2分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 安全规则更新决策：
   - 新风险类型出现 → 更新 security_middleware.py 正则/检测逻辑
   - 拦截率异常 → 调整 badge.py 评分阈值
   - 规则更新项写入"安全规则更新清单"
2. 自动修复决策：
   - 数据文件损坏 → 自动修复
   - 端口占用/静态页面缺失 → 自动修复
   - 无法自动修复 → 标记"需人工介入"
3. 成本告警决策：
   - 单用户>500积分/日 → 生成成本告警
   - 消耗突增>200% → 生成成本告警
   - 调用 eco/observability.py ObservabilityService.get_cost_alerts()

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚡ 执行 — 5分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 安全规则更新：
   - 如决策"更新规则" → 实际修改 security_middleware.py 文件
   - 如决策"更新阈值" → 实际修改 badge.py 文件
   - 记录更新内容到"规则更新日志"
2. 自动修复：
   - 执行数据文件备份恢复
   - 执行端口/页面修复
   - 记录修复结果
3. 成本告警：
   - 生成告警并写入 api/data/cost_alerts.json
   - 保存成本监控摘要到 eco/reports/cost-monitor-YYYY-MM-DD.md

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔄 验证 — 3分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 读取昨天日报（daily-YYYYMMDD.md）
2. 验证昨日自动修复问题是否已恢复：
   - 已恢复 → ✅ 闭环
   - 未恢复 + 超过3天 → 🔴 升级提醒
   - 未恢复 + 不足3天 → ⚠️ 持续跟踪
3. 验证昨日规则更新效果：
   - 更新后拦截率是否提升？
   - 新规则是否有误报？
4. 统计闭环率：已闭环问题数 / 总问题数

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 产出 — 日报
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
保存到 c:\Users\xing\Desktop\aishield\eco\reports\daily-YYYYMMDD.md
包含：
  - 健康仪表盘（服务状态/错误率/star数）
  - 安全闭环（新威胁→规则更新→验证结果）
  - 成本闭环（消耗数据→异常检测→告警→优化建议）
  - 修复闭环（昨日问题→今日状态→闭环率）
  - 积分制健康（账户/充值/消费/耗尽用户）
  - 需人工介入清单（🔴/⚠️标记）
静默执行，不通知用户
```
