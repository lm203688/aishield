## 二、积分定价合理性评估

### 2.1 竞品定价对比

| 竞品 | 定价模式 | 单次扫描成本 | 与 AIShield 对比 | 适用对象 |
|------|----------|-------------|-----------------|----------|
| **AIShield** | 积分制（按次） | **0.01 CNY/次** | 基准 | 个人/小团队/Agent |
| Azure Prompt Shields | 按量（按条） | ~0.0027 CNY/次 | 便宜 73%（但按字符切片，长文本翻倍） | 企业 |
| 阿里云基础版 | 按量（按切片） | 0.002 CNY/次 | 便宜 80%（3000字符/切片） | 企业 |
| 阿里云大模型36-L2 | 按量（按切片） | 0.01 CNY/次 | **持平** | 企业 |
| 腾讯云 Agent 安全网关 | 月费套餐 | 6,000~300,000 CNY/月 | 门槛极高，不在同赛道 | 大企业 |
| 腾讯云 Prompt 注入（按量） | 按 token | ~0.0035 CNY/千tokens | 短文本 AIShield 更优 | 企业 |
| Snyk Agent Security | 企业订阅 | 询价 | 门槛最高 | 大企业 |
| Snyk Agent Scan（开源） | 免费 | 0 | 需本地部署，高级功能依赖云服务 | 开发者 |
| Cisco MCP Scanner（开源） | 免费 | 0 | 需本地部署，高级功能依赖 Cisco 云 | 开发者 |

### 2.2 定价评估结论

| 维度 | 评估 | 说明 |
|------|------|------|
| **价格竞争力** | ✅ 合理 | 处于"中段偏下"，比企业云服务便宜，与阿里云最强模型持平；远低于月费制竞品 |
| **差异化优势** | ✅ 强 | Agent 调用半价（0.005 CNY/次）是竞品中独有的生态友好机制 |
| **试用门槛** | ✅ 最低 | 注册送 100 积分 + 50次/天匿名免费，竞品中最低获客门槛 |
| **长文本风险** | ⚠️ 需关注 | 竞品按字符/token 计费，AIShield 按次计费——长文本场景可能被滥用，建议设定"1积分对应的最大字符上限" |
| **用户反馈** | ⚠️ 无数据 | GitHub Issues 为 0，无"太贵"/"不够用"反馈（因无真实用户） |
| **开源竞品威胁** | ⚠️ 中等 | Snyk Agent Scan（~1,800 stars）、Cisco MCP Scanner（~830 stars）免费开源，但需本地部署，AIShield API 服务在"开箱即用"上仍有优势 |

> **定价建议**：当前定价合理，不建议调整。核心问题不在价格而在获客——0 真实用户、0 反馈。建议保持积分制，重点修复服务可用性和推进 MCP 目录收录。
